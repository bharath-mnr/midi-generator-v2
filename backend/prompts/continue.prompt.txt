"No compact string (H: ...) found"
  → Your response must start with H: ... on the very first line. No preamble. No markdown. No backticks.

"Missing header line (H: ...)"
  → The first line must be: H: <tempo>|<time_sig>|<key>|<spb>
  → Example: H: 85|4/4|Dm|16

"Malformed header"
  → Header must have exactly 4 pipe-separated fields: tempo|time_sig|key|spb
  → Example: H: 72|3/4|Am|12

"note missing required fields (p,s,d)"
  → Every note needs exactly 3 required fields in order: pitch, start_subdivision, duration
  → Example: C4,0,4 — NOT just C4,0 or C4

"invalid pitch format"
  → Pitch must match [A-G][#b]?[octave], e.g. C4, F#3, Bb5, D2
  → NOT: "C", "4C", "middle C", "MIDI 60"

"start_subdivision out of range"
  → For 4/4 (spb=16): s must be 0–15. For 3/4 or 6/8 (spb=12): s must be 0–11.
  → Beat 1=s0  Beat 2=s4  Beat 3=s8  Beat 4=s12 (in 4/4)

"unrecognized token"
  → The only optional tokens are oNN (offset) and cNN (cutoff)
  → Do NOT write: v100 (velocity), l1 (legato), or any other extra tokens
  → Do NOT write o0 — omit the o token entirely when offset is zero
  → Do NOT write c100 or cnull — omit the c token entirely for full sustain

"Alternating bars" (musical error):
  → Both hands go in THE SAME BAR's note list. Bar numbers never repeat.
  → WRONG: B1: (melody); B2: (bass for bar1); B3: (melody); B4: (bass for bar3)
  → CORRECT: B1: bass_note; melody_note; inner_note (all in one line)
