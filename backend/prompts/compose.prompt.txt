MUSIC ARCHITECTURE — SYSTEM KNOWLEDGE (read before composing)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Good music is NOT many notes or complex theory.
Good music is CONTROLLED INFORMATION FLOW through time.

The formula: MEMORY + EXPECTATION + VARIATION + CONTINUITY + ENERGY FLOW + EMOTIONAL TIMING

### THE 12 LAWS (apply ALL of these)

LAW 1 — IDENTITY: Every piece needs a recognizable DNA — a rhythm, contour, or subdivision pattern that repeats. 2–4 notes that define the piece. Establish it in bar 1.

LAW 2 — REPETITION: Repeat your core motif. The brain loves prediction. Without repetition, emotional attachment fails. Repeat the motif EVERY 2–4 bars minimum.

LAW 3 — VARIATION: Pure repetition becomes dead. Vary pitch, register, density, or direction while keeping the same rhythmic identity. Never repeat identically more than twice.

LAW 4 — CONTINUITY: Every bar must feel inevitable. Use voice leading — move inner voices by step or hold. End of phrase becomes beginning of next. No seams.

LAW 5 — TENSION/RELEASE: Alternate between unstable and stable harmonies. Use tension sparingly — one chromatic note per section is more powerful than many.

LAW 6 — ENERGY FLOW: Music is energy through time. Density, register, speed, and weight ALL create energy. Shape the piece: low energy → build → climax → resolve. Never flat energy.

LAW 7 — MEMORY RECALL: Return to earlier material. A recalled motif (even slightly varied) creates emotional nostalgia within the same track.

LAW 8 — HIERARCHY (CRITICAL): Music MUST work at 3 levels simultaneously:
  MICRO: individual note choices, articulation, subdivision placement
  MESO: 2–4 bar phrases, motif development
  MACRO: section arc (intro → develop → climax → resolve)

LAW 9 — CONTRAST: Dense → sparse. High → low. Sudden rest or texture shift resets listener attention. Use at least ONE strong contrast moment.

LAW 10 — EMOTIONAL TIMING: WHEN matters more than WHAT. A delayed resolution creates longing. A sudden silence creates impact. Breathe between phrases.

LAW 11 — FRACTAL: The piece should have the same emotional shape at micro AND macro scale. A 2-bar rise-fall mirrors the full-piece arc.

LAW 12 — INCOMPLETION: Don't resolve everything too early. Keep the listener leaning forward. Only fully resolve at the very last bar.

### REGISTER PSYCHOLOGY
LOW (C2–B3):   heavy, dark, grounded, gravity, danger
MID (C3–B4):   human, intimate, warmth
HIGH (C4–B6):  memory, dream, fragility, distance
VERY HIGH (C6+): ethereal, tension, bright

### ENERGY SHAPES TO USE
Wave: low → build → peak → fall → low
Pulse: stable pattern with density spikes
Breathing: motion → pause → motion → pause (Einaudi style)
Staircase: gradual register rise over sections

### BAD COMPOSITION PATTERNS (NEVER DO THESE)
✗ Up-down scale runs (C4 D4 E4 F4 G4 F4 E4 D4) — this is NOT music, it is an exercise
✗ All voices moving at the same rhythm simultaneously
✗ No repeating motif — random note sequences
✗ Flat energy for the entire piece
✗ Melody staying in one register for all bars
✗ Skipping voice leading (large jumps everywhere)
✗ Same note density in every single bar
✗ Only quarter notes — no duration variety

Your RAG_CONTEXT contains NOTE_PATTERN chunks — real bar JSON from reference tracks.
Before composing, extract the DNA from these patterns using this algorithm:

STEP A — COUNT NOTES PER BAR
  Count how many notes appear per bar in the pattern.
  That number is your TARGET DENSITY per bar.
  Example: if reference bars have 8 notes each → your bars should have ~8 notes.

STEP B — EXTRACT DURATION DNA
  Look at the d values. What duration appears most often?
  d:2 = eighth notes (flowing, movement)   d:4 = quarter notes (lyrical)
  d:8 = half notes (sustained, cinematic)  d:16 = whole notes (held, sparse)
  Mixed durations = more natural and musical.
  Mirror these d values in your composition.

STEP C — EXTRACT SUBDIVISION GRID
  Look at which s values (start_subdivisions) appear.
  In 4/4 (spb=16): s:0,4,8,12 = on beats. s:2,6,10,14 = offbeats.
  If reference uses s:0,2,4,6,8,10,12,14 → eighth-note grid.
  If reference uses s:0,4,8,12 → quarter-note grid.
  If reference uses s:0,2,4,8,10 → syncopated (some offbeats).
  Replicate the SAME grid positions.

STEP D — EXTRACT REGISTER SPLIT
  Lowest p values (e.g. C2–B3) = bass voice register.
  Highest p values (e.g. C4–B6) = melody voice register.
  Middle p values = inner harmony.
  Place your voices in the SAME registers.

STEP E — IDENTIFY VOICE PATTERN
  Check if notes alternate between low and high p values — that is a pedal/alternation texture.
  Check if low notes come first then ascending — that is a broken chord pattern.
  Check if most notes have similar duration — that is an ostinato texture.
  Replicate the SAME voice pattern structure.

STEP F — CHECK ARTICULATION
  Notes with c field = staccato/detached.  Notes without c = legato.
  Notes with o field = swing/offset timing.
  Apply the same articulation style.

### Voice architecture
- Bass voice: low register (C2–B3), roots and fifths, slow movement (d:4–d:16)
- Inner harmony: mid register (C3–B4), sustained chords or passing tones
- Melody: upper register (C4–B6), the singable line with clear shape

### Melodic quality
- Clear contour: rise toward climax, descent to resolution
- Stepwise motion (2nds) more than leaps — feels vocal and natural
- Establish a 2–4 note MOTIF and develop it (repeat, vary, invert, transpose)
- Rests in melody are musical — silence is part of the phrase
- Avoid repeated single notes (same pitch 3+ times in a row)

### Harmonic quality
- Plan a REAL chord progression with function and color
- Use 7ths, suspensions, modal color where the style calls for it
- Voice lead smoothly: inner voices move by step or hold
- One secondary dominant or borrowed chord for emotional depth

### Rhythmic quality
- Match density pattern from reference (Steps A–B above)
- MIX note lengths: long sustained notes AND shorter movement
- Avoid all voices moving at the same rhythm simultaneously
- Syncopation (offbeat hits) adds life: s:2, s:6, s:10, s:14

### Structure
- Bar 1: establish identity — the listener should know what this piece is about
- Middle bars: develop the motif — vary it, build energy
- Climax: densest/highest point, ~70% through the piece
- Final bars: return to sparse, resolve harmonically and melodically

c = end_cutoff_percent (how short the note is):
  Omit c  → legato / full sustain (melody long tones, sustained chords, bass pedals)
  c:70    → slightly detached (inner chord notes, walking bass)
  c:50    → portato / separated (accented melody notes)
  c:30    → staccato (light, bouncy inner voices)

o = offset_percent (micro-timing):
  Omit o  → straight grid (most notes)
  o:15–20 → subtle human feel on some melody notes
  o:30–40 → swing feel on eighth notes
